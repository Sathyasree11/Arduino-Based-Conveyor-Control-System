# Arduino Based Conveyor Control System

## Student Details
Name: Sathyasree
Domain: Embedded Systems

## Project Description
This project controls a DC motor conveyor system using Arduino Uno.

Features:
- Forward Direction Control
- Reverse Direction Control
- Speed Control using Potentiometer
- 16x2 LCD Display
- L293D Motor Driver

## Components Used
- Arduino Uno R3
- L293D IC
- DC Motor
- 16x2 LCD
- 10K Potentiometer (Speed Control)
- 10K Potentiometer (LCD Contrast)
- Push Buttons (Forward & Reverse)
- Breadboard
- Resistor

## Tinkercad Link
https://www.tinkercad.com/things/gwqBvjKYQao-arduino-based-conveyor-control-system-sathyasree

## Working
1. Potentiometer controls motor speed.
2. Forward button rotates motor clockwise.
3. Reverse button rotates motor anticlockwise.
4. LCD displays motor speed and direction.
